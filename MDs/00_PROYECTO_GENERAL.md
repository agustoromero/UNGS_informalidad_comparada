# PROYECTO GENERAL
# Proyecto: Comparación Internacional de Informalidad Laboral

## Objetivo

Construir una base armonizada de microdatos de encuestas de hogares para comparar la estructura ocupacional y la informalidad laboral entre países latinoamericanos.

El objetivo no es únicamente medir la informalidad, sino estudiar los cambios estructurales ocurridos entre dos momentos del tiempo utilizando una definición productivista de informalidad.

Actualmente se trabaja con:

- Argentina
- Brasil
- Chile
- Colombia
- México
- Perú

## Años

El objetivo final del proyecto es cubrir:

- 2007
- 2018
- 2023

Actualmente existen desarrollos completos para parte de 2018 y 2023.

2018 se conserva porque sirve para validar la metodología y realizar comparaciones intermedias.

## Unidad de análisis

Personas de entre **15 y 65 años**.

## Definición de informalidad

El proyecto **no utiliza una definición legalista** basada únicamente en registro o aportes.

Se adopta una **definición productivista**, basada en literatura internacional sobre estructura ocupacional.

La clasificación combina:

- categoría ocupacional
- tamaño del establecimiento
- educación
- tipo de empleo
- otras variables armonizadas

## Clasificación ocupacional

La estructura principal es:

### Sector formal

- Patrones
- Asalariados privados
- Asalariados públicos
- Autónomos profesionales

### Sector informal

- Patrones de microestablecimientos
- Asalariados privados de microestablecimientos
- Autónomos no profesionales
- Trabajadores familiares
- Servicio doméstico

## Cambio metodológico importante

Anteriormente el proyecto utilizaba:

- microestablecimiento <5 trabajadores

La versión actual utiliza:

- microestablecimiento <10 trabajadores

Este criterio reemplaza completamente al anterior.

## Autónomos

Anteriormente se distinguían mediante calificación ocupacional.

A partir de esta versión:

Formal:

- terciario completo
- universitario completo

Informal:

- resto de los trabajadores independientes

## Cobertura territorial

Siempre que la encuesta lo permita se producirán indicadores para:

- Total urbano
- Total rural
- Urbano + rural

Cada uno con:

- total
- desagregados

Cuando una encuesta no permita alguno de estos universos deberá documentarse explícitamente.

## Indicadores principales

Se producirán indicadores para:

- PEA
- PET
- Tasa de actividad
- Tasa de empleo
- Estructura ocupacional
- Informalidad
- Indicadores de precariedad

## Indicadores adicionales

Siempre que existan variables comparables se calcularán:

- subocupación demandante
- subocupación no demandante
- contrato escrito
- contrato verbal
- contrato permanente
- contrato temporal

## Sector público

El empleo público deberá desagregarse, cuando sea posible, en:

- Administración pública
- Educación
- Salud

## Salarios

En una etapa posterior se incorporarán:

- salario real
- ocupación principal
- índices de precios por país

Esta etapa no forma parte aún del pipeline principal.

## Filosofía del proyecto

La prioridad absoluta es la armonización internacional.

Cuando una variable no exista:

1. buscar equivalente conceptual;
2. buscar proxy comparable;
3. recién entonces considerar missing.

Nunca asumir automáticamente que una variable es inexistente.

Toda decisión metodológica debe quedar documentada.
